# 面板计算规则

本文件是 `frontend/legacy/pages/guide.html`（面板计算方式学习指南）的可维护文本版。
规则真源最终以 `backend/src/zzz_panel/core/` 为准。

## 基础规则

- **攻防血**：`基础值 × (1 + 百分比) + 固定值`
- **冲击力 / 异常掌控 / 能量回复**：`基础值 × (1 + 百分比)`
- **暴击率 / 暴击伤害 / 增伤 / 穿透率 / 异常精通 / 穿透值**：纯加法

## 音擎（武器）

- 除锋御音擎提供**基础防御力**外，其余提供**基础攻击力**。
- 音擎基础值与代理人基础值**先相加，再乘百分比**。
- 音擎固定副词条按其性质并入：百分比类走加法，固定值类走加法。

## 核心技

- 核心加成分三类：`pct`（百分比）、`flat`（固定值）、`base`（基础值）。
- `base` 类（如「基础攻击力 +75」「基础生命值 +420」）**并入基础值**，再参与百分比计算。
- 核心技共 2 个槽位。

## 驱动盘

- 1 号固定：生命 +2200
- 2 号固定：攻击 +316
- 3 号固定：防御 +184
- 4 号主词条：6 选 1（攻击 30% / 生命 30% / 防御 48% / 暴击率 24% / 暴击伤害 48% / 异常精通 92）
- 5 号主词条：5 选 1（攻击 30% / 生命 30% / 防御 48% / 穿透率 24% / 增伤 30%）
- 6 号主词条：6 选 1（攻击 30% / 生命 30% / 防御 48% / 冲击力 24% / 异常掌控 30% / 能量回复 60%）

## 副词条

10 种，每条固定数值：小生命 112、大生命% 3、小攻击 19、大攻击% 3、小防御 15、
大防御% 4.8、暴击率 2.4、暴击伤害 4.8、穿透值 9、异常精通 9。

**总条数上限 54**。输入超过时自动回退超出部分（见 `calculator.js` 的 `handleSubInput`）。

## 二件套

共 3 组，每组可选 1 个二件套效果。

## 面板模式

| 模式 | 说明 | 专属公式 |
| --- | --- | --- |
| `standard` | 通用 | 无 |
| `rupture` | 命破 | 贯穿力 = 0.3 × 最终攻击力 + 0.1 × 最终生命值 |
| `fengyu` | 锋御 | 实际暴击率 = 最终暴击伤害 × 35% + 原最终暴击率 |

### 锋御固有属性 · 锐暴伤害（已完成建模）

- **数值固定为 150%**：不读取任何输入，不参与任何词条、音擎、套装、核心技或修正系数的计算。
- **适用范围仅限锋御最终面板**：只在锋御（`fengyu`）代理人的最终面板中显示一项
  「锐暴伤害：150%」，与「实际暴击率」并列。基础面板输入区、驱动盘、音擎、二件套、
  核心技等任何其他位置均不出现该项；非锋御模式下面板不显示该项。
- **实现位置**：前端 `fengyu_blast_result` 行取值来自 `FENGYU_BLAST_DMG`；
  Python 核心仅在 `fengyu` 模式响应中返回 `fengyu_blast_dmg`。两端均不把它加入伤害加成或其他计算。

锋御模式下，`能量自动回复` 相关文案统一替换为 `锐能自动累积`。

## Python 实现现状

`backend/src/zzz_panel/core/panel.py` 目前实现了基础规则、音擎、核心百分比、驱动盘词条、
二件套、二级百分比属性与穿透值/异常精通加法。

**待迁入 Python 的条目**（这些规则本身**均已建模**并在前端计算器中生效，此处仅表示
尚未在 Python 侧重写，属 Vue3 迁移第 3 步的代码搬迁任务，不代表规则缺失或未建模）：

- 驱动盘 1/2/3 号固定词条（→ `core/constants.py`）
- 副词条按条数换算、3 组二件套的完整编排（→ `core/modifiers.py`）
- 计算明细来源追溯（→ `core/breakdown.py`）
- `penforce` / `energy_accumulation` 输入字段

迁移时**以 `frontend/legacy/scripts/calculator.js` 为行为基准**，Python 侧现有实现仅作公式参考。
逐项差异见 [architecture.md](architecture.md) 与 `docs/migration-vue3.md`。

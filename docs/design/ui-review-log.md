# UI 验收记录与先例表

本文件是人工 UI 验收的**唯一记录处**，同时充当 C 档裁定的**先例表**。

用法见 [ui-review-checklist.md](ui-review-checklist.md)。核心约定：

- 每轮验收填一份记录（模板见清单第 7 节）；
- **先例优先**：下一轮遇到同类场景，先查本文件的先例表，有先例直接照抄；
- 只有本文件里没有先例的场景，才走当轮的判断。

## 先例表

> 格式：`场景` → `结论` → `依据`。被引用时直接写「照先例 #N」。

| # | 场景 | 结论 | 依据 |
| --- | --- | --- | --- |
| 1 | 卡片用「描边 + 阴影 + 底色」三件套 | **去掉描边**，只留阴影 + 底色 | 三件套同时用会把页面切成一堆小格子（§8.5.1/§8.5.2） |
| 2 | 六大模块的顺序信号 | **01–06 序号徽标**（中性深底白字），色条只作分区装饰 | 徽标承载信息且对比度 17.7:1；色条不承载信息 |
| 3 | 模块标题旁的彩色标签 | **保留彩色**（与指南页提示框同源） | 标签色是**跨页面一致的语义色**，不是装饰；砍掉会让指南页的颜色失去解释 |
| 4 | 结果区在未载入代理人时 | **保留 12 行**（通用默认值），加**状态行**说明 | 隐藏它会破坏三方对拍（legacy 恒渲染 12 行）；状态行解决「误读成结果」 |
| 5 | 正文行长上限 | **40em**（≈40 个汉字） | 中文一字 = 一 em；40 字一行是舒适上限 |
| 6 | 副标题（题引）的行长 | **不受上限约束** | 题引是一到两句的引子，40em 会把一句 52 字的话折成「40 字 + 12 字」的碎块 |
| 7 | 启动页卡片的大号序号（01/02/03） | **保留低对比的「幽灵数字」** | 48px 装饰性序号，1.49:1 不足以读出内容，但卡片顺序由布局承担；不计入对比度闸门 |
| 8 | 截图工具 | **CDP（`frontend/tools/screenshot.mjs`）**，不用 `--window-size` | Chrome 在 Windows 上把宽度钳到最小 500px，截出来的图与声明的视口对不上 |

**C 档**：仍缺「修缮前」锚点图（需从 git 历史检出再拍一批）。

**计算侧结论**（`backend/tests/test_two_plus_two_plus_two.py`）：

- 两份**同效果**的 2 件套（月光骑士颂 + 摇摆爵士，都是「能量回复 +20%」）**都生效**；
- 同一修正量的百分比**相加**后一次性作用（+20% + 20% = +40%），**不是**叠乘；
- 三组的**组序不影响**结果。

**先例补充**：

| # | 场景 | 结论 | 依据 |
| --- | --- | --- | --- |
| 11 | 「组」与「候选」同名近义，易混 | **组**用 `set2`/`set2b`/`set2c`（并列，都要装）；**候选**用组内 `main`/`alt`（二选一，可为数组） | 洛克茜的月光 + 摇摆：两组同效果但都要装，与「摇摆/月光二选一」是**两种不同的东西** |
| 12 | 同一修正量的多个百分比来源 | **相加**后一次性作用 | 游戏语义；叠乘会高估（+20%+20% ≠ ×1.2×1.2） |

# 伤害公式与乘区规格

本文是**伤害引擎**的规格真源：乘区怎么分、每个乘区怎么算、有效范围是什么、
局内局外与快照实时怎么划。

- 面向实现：`backend/src/zzz_panel/` 下的 `core/damage/` —— **已建**（`zones.py` 纯乘区函数 +
  `engine.py` 装配），照本文实现，**不得自行发明公式**。
- 面向验证：第 6 节的**验收契约**逐条可写成测试用例 —— **已落成**
  `backend/tests/test_damage_zones.py`（30 条，一个条款一个测试，编号与本文一致）。
- 与面板规则的关系：面板（局外静态）见 [calculation-rules.md](calculation-rules.md)；
  本文只管**伤害**。两者共用同一份规则表与预设。

> **口径**：伤害引擎在**局外口径**（0 影画 + 专武）上工作，与毕业面板同口径。
> 影画、专武局内加成、4 件套、队伍增益**不进引擎**——它们是攻略层的文字说明。
> 见 [calculation-rules.md](calculation-rules.md) §0「面板口径」。

## 1. 引擎的边界

| 引擎**做** | 引擎**不做** |
| --- | --- |
| 给定配装 → 算出一个伤害值（或一组） | 时间轴、能量循环、轴切与配队时序 |
| 在配装空间内搜索最优 | 异常积蓄的**过程**（只算积蓄值本身） |
| 以伤害为目标函数比较两套配装 | 掉落概率、养成规划、账号与云端存档 |

> **为什么不做完整战斗模拟**：异常伤害依赖「积蓄时加权 + 结算时实时」两套读数，
> 完整模拟要建模积蓄时长与触发节奏，成本极高而收益递减。本引擎把两者都当作
> **可配置输入**（见第 4 节），对「这套配装强不强」这个问题的回答是充分的。

## 2. 乘区总纲

三条伤害路径的乘区**不同**，不能混用：

```
常规伤害 = 基础伤害区 × 增伤区 × 暴击区 × 防御区 × 抗性区 × 减易伤区 × 失衡易伤区 × 特殊乘区
贯穿伤害 = 基础伤害区 × 增伤区 × 暴击区 × 贯穿增伤区 × 抗性区 × 减易伤区 × 失衡易伤区 × 特殊乘区
异常伤害 = 基础伤害区 × 增伤区 × 异常精通区 × 防御区 × 抗性区 × 减易伤区 × 失衡易伤区
           × 伤害等级区 × 异常增伤区 × 异常暴击区
```

**五条容易做错的归属规则**：

| 规则 | 内容 |
| --- | --- |
| **增伤区分四类** | 常规增伤区、贯穿增伤区、异常增伤区、直接攻击增伤区**是四个不同的乘区**，互相**不稀释**。属性异常增伤 / 紊乱增伤 / 异放增伤 / 乱流增伤**同属异常增伤区**（相加） |
| **增伤区是加算区** | 同一区内多个来源**相加**后再乘；跨区才相乘 |
| **增伤区也能减伤** | 「造成的伤害降低 X%」属于**增伤区**，不是减易伤区 |
| **异常不吃暴击区** | 异常伤害用**异常暴击区**（异常暴击率 × 异常暴击伤害），不是常规暴击区 |
| **贯穿不吃防御区** | 贯穿伤害用**贯穿增伤区**替代防御区 |

## 3. 各乘区定义

### 3.1 基础伤害区

```
基础伤害区 = Σ(伤害倍率 × 对应属性)
攻击力 = [基础攻击力 × (1 + 局外攻击力%) + 局外数值攻击力] × (1 + 局内攻击力%) + 局内数值攻击力
```

三类特例：

| 类型 | 基础属性 | 备注 |
| --- | --- | --- |
| 常规伤害 | 攻击力 | |
| **贯穿伤害**（命破） | **贯穿力** | `贯穿力 = 0.3 × 攻击力 + 0.1 × 生命值上限`——**所有命破代理人统一**这个比例（游戏内文案各写各的，但实际结算公式一致） |
| **锐化伤害**（锋御） | **防御力** | 锋御的直伤统称「锐化伤害」，把常规公式里的攻击力换成防御力；锋御音擎的基础属性**无一例外**是基础防御力 |
| **真实伤害** | 目标最大生命值 | 只算基础伤害区的纯伤害，部位破坏的伤害属于这类 |

> **命破 / 锋御的异常伤害仍用攻击力**——只有直伤换口径，异常伤害照旧。

> **命破无视 100% 防御**：贯穿伤害的防御区乘数恒为 **1.000**（对任何敌人都一样）。
> 由此得到官方的两个对比数字：对 60 级以上首领，贯穿伤害是常规伤害默认情况的 **2.2 倍**；
> 对「高防怪」，命破角色的防御区乘数是无穿透/减防非命破角色的 **3 倍**。

> 游戏里的**伤害显示是向上取整**的，多段伤害逐段取整再相加。

### 3.2 增伤区

```
增伤区 = 1 + Σ(增伤)
```

| 有效范围 | `[0, 6]` |
|---|---|

来源：属性增伤（**元素限定**）、技能类型增伤、攻击类型增伤、全类型增伤，以及
「造成的伤害降低」。

- 属性增伤共 7 种属性（火 / 电 / 冰 / 物理 / 以太 / 烈霜 / 玄墨），
  但**只有火、电、冰、物理、以太 5 种**进增伤区；烈霜按冰、玄墨按以太结算。
- 「追加攻击」类效果除自身标签外，还带来源的技能类型与攻击类型标签。
- 描述像「易伤」的效果（如朱鸢的[以太余烬]）**仍然进增伤区**。

> **本项目只有一行「属性伤害」**（`dmg` 累加器），且它按**角色自身属性**计。
> 5 号位主词条是「属性伤害 +30%」；属性伤害类 2 件套**不计入面板**
> （见 [calculation-rules.md](calculation-rules.md) §6），因此当前面板口径下
> `dmg` 只可能来自 5 号位。

### 3.3 暴击区 / 异常暴击区

```
暴击区：   暴击时 1 + 暴击伤害；   未暴击时 1
暴击期望 = 1 + 暴击率 × 暴击伤害
异常暴击区：暴击时 1 + 异常暴击伤害；期望 1 + 异常暴击率 × 异常暴击伤害
```

| 项 | 范围 |
| --- | --- |
| 暴击率 | `[0, 1]`（锋御可超 100%，见 §3.12） |
| 暴击伤害 | `[0, 5]` |
| 暴击区 | `[1, 10]` |

代理人基础暴击率 5%、基础暴击伤害 50%；敌人基础暴击率 0、基础暴击伤害 50%。

### 3.4 防御区

```
防御区 = 攻击方等级基数 / (受击方有效防御 + 攻击方等级基数)

受击方有效防御 = 受击方防御 × (1 − 攻击方穿透率%) − 攻击方穿透值      # 下限 0
受击方防御 = (基础防御 × (1 + 初始防御%) + 初始固定防御) × (1 + 防御加成% − 防御降低%)
```

代入**对敌**场景（无局外加成为 0）可简化为：

```
敌人有效防御 = 基础防御 × (1 + 防御加成% − 防御降低% − 无视防御%) × (1 − 穿透率%) − 穿透值
```

| 有效范围 | 防御区 `(0, 1]`，**游戏内可达下限 0.0283**；受击方有效防御 `≥ 0` |
|---|---|

**两条必须记住的算术关系**：

- **无视防御与减防加算**，**穿透率与减防乘算**——两者不是一回事。
- 减防是敌人身上的 debuff（全队吃），无视防御是技能级的；数值上等价。

**锚点数值**（写测试用）：

| 项 | 值 |
| --- | --- |
| 攻击方等级基数 | 60 级及以上恒为 **794**（超过 60 仍是 794） |
| 敌人某等级基础防御 | `1 级基础防御 / 50 × 该等级攻击方等级基数`，60 级封顶不再成长 |
| 1 级基础防御 | 普通敌人 **36~46**、精英 **45~54**、杜拉罕 **58**、首领 **60**（→ 60 级为 **952.8**） |
| **60 级打 60 级以上首领的默认防御区** | `794 / (952.8 + 794) = **0.4545**` |

### 3.5 抗性区

```
抗性区 = 1 − 受击方抗性 + 受击方抗性降低 + 攻击方无视抗性
```

| 有效范围 | `[0, 2]` |
|---|---|

- 敌人的**弱点属性抗性 = −0.2**（抗性区 1.2）、**抗性属性抗性 = +0.2**（抗性区 0.8）。
- 霜寒与玄墨没有独立抗性，按冰 / 以太结算。
- 抗性是**按属性**的，同一个敌人对不同属性的抗性不同。

### 3.6 异常侧乘区

```
异常精通区 = 异常精通 / 100                          # 有效范围 [0, 10]（1.4 前为 [0, 6]）
伤害等级区 = trunc(1 + (等级 − 1) / 59, 4)          # 1 级 = 1，60 级 = 2
异常增伤区 = 1 + Σ(异常增伤)                        # 属性异常 / 紊乱 / 异放 / 乱流，相加
异常掌控区 = 异常掌控 / 100                          # 向下取整；有效范围 [0, 3]
异常暴击区 = 暴击 1 + 异常暴伤；期望 1 + 异常暴率 × 异常暴伤
异常积蓄值 = 基础异常积蓄值 × 异常掌控区 × 异常积蓄效率区 × 异常积蓄抗性区 × 距离衰减区
异常积蓄效率区 = 1 + 异常积蓄效率提升 + 异常积蓄值提升 − 异常积蓄效率降低
异常积蓄抗性区 = 1 − 异常积蓄抗性 + 异常积蓄抗性降低
```

- **异常掌控必须向下取整**（不是四舍五入）：积蓄公式读它，带小数会算出
  `38.332` 这种不可能的暴击率。
- 「异常积蓄效率提升」与「异常积蓄值提升」是**同一个效果**，统一描述。
- 异常积蓄**不随等级成长**，每个技能的基础积蓄值几乎独一无二，**一般只能查表**。
- 触发阈值与敌方等级无关，只与**等阶**（普通 / 精英 / 首领）和**已触发次数**有关：
  普通 : 精英 : 首领 = 4 : 15 : 20，物理异常阈值是其他属性的 1.2 倍。

#### 3.6.1 紊乱倍率（按基底异常）

紊乱的**伤害倍率** = `450% + 时间项`。`t` 是基底异常的**已流逝时间**（秒），
`T = 10 − t` 是基础持续时间 10 秒下的剩余时间：

| 类别 | 基底异常 | 属性 | 固定倍率 | 时间项 |
| --- | --- | --- | ---: | --- |
| 持续伤害类 | 灼烧 | 火 | 450% | `floor((10 − t) / 0.5) × 50%` |
| 持续伤害类 | 感电 | 电 | 450% | `floor(10 − t) × 125%` |
| 持续伤害类 | 侵蚀 | 以太 | 450% | `floor((10 − t) / 0.5) × 62.5%` |
| BUFF 类 | 霜寒 | 冰 | 450% | `floor(10 − t) × 7.5%` |
| BUFF 类 | 畏缩 | 物理 | 450% | `floor(10 − t) × 7.5%` |

- `t` 与 `T` 不能混：本表用已流逝 `t`；乱流表（§3.13）用剩余 `T`。
- 持续时间被延长时，用**有效持续时间**替换 `10`，并把 `t` 夹在
  `[0, 有效持续时间]`；事件存储不得按基础时长截断。
- 本表只给伤害倍率；**紊乱失衡倍率恒为 200%**（§3.10）是另一件事。
- 烈霜 / 玄墨的紊乱倍率未给出，**不得臆造 0**；按官方后续数据补。
- 紊乱的其它乘区（异常增伤 / 异常暴击等）仍按 §3.6 与参考实现的边界处理，
  本表不改变乘区归属。

### 3.7 减易伤区 / 失衡易伤区

```
减易伤区 = 1 + 受击方易伤 − 受击方减伤
失衡易伤区 = 失衡时 1 + 失衡易伤倍率；未失衡时 1 + 未失衡倍率
```

| 乘区 | 有效范围 |
| --- | --- |
| 减易伤区 | `[0.2, 2]`（叠减伤**到不了**无伤） |
| 失衡易伤区（失衡时） | `[0.2, 5]` |
| 失衡易伤区（未失衡时） | `[1, 3]` |

敌人的失衡易伤倍率默认有 **25% / 50% / 100%** 三种，绝大部分是 50% 或 100%。
代理人和邦布**没有失衡条**，敌人打它们时**不计失衡易伤区**。

### 3.8 贯穿增伤区

```
贯穿增伤区 = 1 + 贯穿增伤
```

| 有效范围 | `[0.2, 9]` |
|---|---|

「造成的贯穿伤害降低」也属于这个乘区。

### 3.9 特殊乘区（距离衰减区）

```
距离衰减区：影响【伤害、失衡值、异常积蓄值】三者
```

- **默认型**：与敌人距离超过 15m 时伤害衰减 **25%**，之后每远 5m 再衰减 25%。
- **格莉丝型**：超过 15m 时衰减 **30%**。
- 已有类型：默认型、格莉丝型、扳机型、耀嘉音型。

> 距离衰减对**不同远程代理人的技能**可能用不同类型，实现时按技能查表。

### 3.10 失衡

```
失衡值累积 = Σ(基础失衡区) × 失衡抗性区 × 失衡值提升区 × 受到失衡值提升区 × 距离衰减区

基础失衡区   = 冲击力 × 失衡倍率                    # 冲击力有效范围 [0, 1000]
失衡抗性区   = 1 − 受击方失衡抗性                   # 有效范围 [0, 2]
失衡值提升区 = 1 + 造成失衡值提升 − 造成失衡值降低   # 有效范围 [0, 4]
受到失衡值提升区 = 1 + 受到失衡值提升 − 受到失衡值降低 # 有效范围 [0, 4]
```

- 弱点属性的失衡抗性 −20%（→ 1.2）、抗性属性 +20%（→ 0.8），**没有特例**，
  与伤害抗性、异常积蓄抗性是**三个不同的属性**，不要混用。
- **紊乱失衡倍率恒为 200%**；紊乱失衡 = 上式 × 失衡等级区，
  `失衡等级区 = 1 + 0.0075 × 等级`（1 级 1.0075，60 级 1.45）。
  这是**失衡值**的倍率；紊乱的**伤害倍率**见 §3.6.1（450% + 时间项），两者不要混用。
- **6 号位「冲击力」主词条是提升失衡值的渠道之一**，与穿透率 / 穿透值无关。

### 3.11 已知需要单独建模的变体

| 变体 | 乘区构成 | 状态 |
| --- | --- | --- |
| **极性紊乱** | 基础伤害区 = `15% × (结算的紊乱伤害倍率 + 250%) × 攻击力 + xx% × 异常精通` | 需按具体代理人的紊乱参数单独核对 |
| **耀变**（蕾米埃尔） | **不是常规伤害事件的乘区变体**——参考实现把它建模为**独立的队伍异常评分**（`zzz_calculator:docs/luminescence-modeling.md`：「不把评分伪装成可加入普通循环的伤害事件」），有**专用异化公式**，**不读取队友异化乘区**，且**流明直伤事件不得进入、叠加或改变该评分** | **本期不实现**；若要排期，应按「独立评分」而非「乘区变体」建模 |

### 3.12 锋御（锐化伤害 / 锐化增伤 / 锐暴伤害）

锋御是 3.2 版本新增的职业，它**不是**「常规伤害换个基础属性」那么简单——
有三个专有结构：

| 结构 | 规则 |
| --- | --- |
| **锐化伤害** | 锋御的直伤统称锐化伤害，用**防御力**作为基础属性。乘区构成与常规伤害相同，只是攻击力 → 防御力 |
| **锐化增伤** | **独立乘区**（约 10%），与常规增伤区**独立计算**、互不稀释——与命破的贯穿增伤区同理 |
| **锐暴伤害** | 锋御暴击时**不用暴击伤害结算**，而用**锐暴伤害**（基础 150%）；且**暴击率可以超过 100%**，超出的部分会**再判定一次锐暴** |

**暴击区的平方项结构**（`k = 1 + 锐暴伤害`）：

```
暴击一次 → k
暴击两次 → k²
期望：暴击率 ≤ 100%  →  c × k
      暴击率 > 100%  →  k × [1 + (c − 1) × k]
```

官方原话是「暴击率多个 -1，然后外层再乘一次 (1 + 锐暴伤害)」。
默认锐暴伤害 150% 时：暴击一次 ×2.5、两次 **×6.25**——锐暴伤害在公式里是**平方项**。

> **代价**：锐暴伤害**无法通过驱动盘词条堆**（只能靠角色额外能力 / 影画 / 套装 / Boss 加成），
> 所以它的乘区贡献大但不可控。

**锋御的四个额外约束**（参考实现 core/sharpDamage.js 的 
esolveSharpProfile）：

| 约束 | 值 / 规则 |
| --- | --- |
| **暴击率上限** | **200%**（常规职业 100% 就吃满溢出，锋御堆到 200% 才溢出） |
| **转模比例** | initialCritDmgToCritRateRatio，**逐角色可配**（克拉蕾 0.35）——不是一个全局常数 |
| **伤害域独立** | 锋御的暴击计算**独立于常规暴击**，不与常规暴击区混算 |
| **暴击模式** | 至少三种：onCrit（未暴击）/ sharpCrit（锐暴）/ lacerationCrit（撕裂暴击）——本项目**只建模了前两者的结构** |

> **撕裂暴击（lacerationCrit）是本项目的缺口**：参考实现把它作为独立暴击模式，
> 而本项目只有「暴击一次 / 暴击两次」的平方项结构。
>
> **重要推论**：锋御的暴击率副词条收益曲线是**波浪形**——
> 97.6%~100% 之间因为「跨阶」收益猛增，而 40% 与 140% 时收益相同；
> 越接近 200% 越被稀释。**暴击率不是「越堆越好」**，锋御要具体分析。

**其它锋御要点**：

- **能量叫「锐能」**，且**不吃驱动盘 6 号位的能量自动回复加成**。
- 能量自动回复基准值：非命破 1.2、命破 2（4 星「真斗」为 0）、锋御（克拉蕾）**1.5**。
- **「残痕 / 毁伤」**是锋御的非数值机制（残痕值满 600 攒一个残痕点，消耗后触发范围毁伤，
  毁伤同样是锐化直伤、同样能二次锐暴）——属局内过程，引擎不做。
- 核心技里的**「暴击伤害以 0.35 的比例转换成暴击率」**是**转模**：
  只对**初始暴击伤害**有效（局内生效的暴击伤害不算）。
  克拉蕾据此得到裸装暴击率 `5% + 50% × 0.35 = 22.5%`——
  **本项目的代理人预设已经把转模结果算进 `base.cr`**（克拉蕾 `base.cr = 22.5` ✓），
  所以规则表**不需要**额外的转模选项；但转模口径要写进文档，免得以后重复计算。

### 3.13 风属性（风化 / 浸染 / 乱流）

| 状态 | 机制 |
| --- | --- |
| **风化** | 风属性异常的基础状态：积蓄满后打断敌人行动并造成一段风属性伤害——与其他属性异常同构 |
| **浸染** | 敌人处于风化时，用火 / 冰 / 电 / 物理 / 以太攻击会触发对应属性的**浸染**，提升风属性与该属性的**直接伤害**。**一次风化期间最多触发一次浸染** |
| **乱流** | **替代紊乱的新异常结算机制**：风化与另一种异常同时存在时**不触发紊乱，改触发乱流**；乱流结算风化之外的另一种属性异常，造成**范围异常伤害**，并把浸染状态强制转换为乱流对应的属性状态 |

**乱流的完整公式**（参考实现 docs/wind-anomaly-modeling.md）：

`
攻击区 × 乱流倍率 × 增伤区 × 异常精通区 × 防御区 × 抗性区 × 异常减易伤区
× 失衡易伤区 × 等级区 ×（异常增伤区 + 乱流增伤区）× 异常暴击区 × 异常爆伤区
`

**乱流倍率表**（按**非风基底异常**分，时间项 T 是该异常的剩余时间）：

| 基底 | 固定倍率 | 时间项 |
| --- | ---: | --- |
| 强击（物理） | 800% | loor(T) × 7.5% |
| 碎冰（冰） | 1300% | loor(T) × 7.5% |
| 灼烧（火） | 900% | loor(T / 0.5) × 50% |
| 感电（电） | 650% | loor(T) × 125% |
| 侵蚀（以太） | 650% | loor(T / 0.5) × 62.5% |
| 烈霜 | 0% | loor(T) × 75% |

**触发关系**：非风异常 A + 非风异常 B 连续触发 → **紊乱**（基于先触发的 A）；
**风化 + 任意非风异常 → 乱流**（不结算紊乱，基于非风异常）；风化本身仍可作为普通属性异常事件。

**事件存储约束**（实现纪律）：乱流事件**只保存**非风基底异常、已流逝时间、次数、失衡状态；
**不保存**风化来源、第二异常来源、来源面板快照、剩余时间或待确认倍率。
事件存储**不得按基础时长截断**（最终计算可能叠加持续时间延长）。

> 乱流**不是一种新的伤害类型**，而是**异常结算路径**——它复用异常伤害的乘区，
> 只是触发条件、倍率与结算对象不同。引擎本期不实现风属性，登记在此。

**乱流的完整公式**（参考实现 docs/wind-anomaly-modeling.md）：

`
攻击区 × 乱流倍率 × 增伤区 × 异常精通区 × 防御区 × 抗性区 × 异常减易伤区
× 失衡易伤区 × 等级区 ×（异常增伤区 + 乱流增伤区）× 异常暴击区 × 异常爆伤区
`

**触发关系**：非风异常 A + 非风异常 B 连续触发 → **紊乱**（基于先触发的 A）；
**风化 + 任意非风异常 → 乱流**（不结算紊乱，基于非风异常）；风化本身仍可作为普通属性异常事件。

**事件存储约束**（实现纪律）：乱流事件**只保存**非风基底异常、已流逝时间、次数、失衡状态；
**不保存**风化来源、第二异常来源、来源面板快照、剩余时间或待确认倍率。
事件存储**不得按基础时长截断**（最终计算可能叠加持续时间延长）。

## 4. 局内 / 局外，与快照 / 实时

### 4.1 局外白值 + 局外绿值 → 战斗白值

```
战斗白值 = 局外白值 + 局外绿值
```

**能量自动回复、攻击力、冲击力**同构：局外基础值（白值）加上局外百分比换算出的
绿值，合并成进战斗时的白值。局内加成再在战斗白值上叠加：

```
攻击力 = [基础攻击力 × (1 + 局外攻击力%) + 局外数值攻击力] × (1 + 局内攻击力%) + 局内数值攻击力
```

> **面板显示的是局外口径**——毕业面板算的是局外值，战斗里的实际值更大。
> 引擎在局外口径上工作，与面板可比。

### 4.2 快照 / 实时

| 读数时机 | 项 |
| --- | --- |
| **积蓄时加权**（一次算定，异常伤害用它的加权和） | 攻击力、增伤、等级、穿透率、穿透值、异常精通、失衡值提升 |
| **结算时实时**（打到的瞬间读） | 抗性、抗性降低、防御降低、无视防御、**无视抗性**、失衡易伤、异常增伤、异常暴击 |

**无视防御与无视抗性不进加权**——它们是实时项。

**来源快照的精确分界**（参考实现的回归契约）：

| 读数 | 规则 |
| --- | --- |
| **自身作为来源** | **实时读取面板** |
| **外部来源**（队友 / 外部快照） | 使用**冻结快照**（含角色、配置哈希、捕获时间、面板、修正参数），**只有刷新才更新**；优化期间固定，**不得实现 A+B 联合驱动盘搜索** |
| **敌人防御 / 抗性 / 事件失衡状态** | 始终**实时** |
| **等级 / 核心技等级** | 当前等级必须**覆盖**存量事件里的等级快照（普通技能与核心技各自覆盖），且在白盒 / 快速总伤 / compiled / dense / 固定评分 / 驱动盘分析 / 优化器里**保持一致** |

**异化的继承边界**：异放只能从**原异常来源**的实时数据或外部冻结快照继承异化，
**触发者侧不得重复乘算**；异化乘区即使有效值为 0 也要显示。

**一个必须记住的数值反例**（维琳娜 2 影异放）：目标防御 953、等级系数 794 时，
2 影异放的防御乘区必须为 **`0.4949970387`**——不得出现按 30% 重复无视算出的
`0.5434261858`。

## 附：耀变（流明）专用异化公式（非伤害事件，队伍评分）

耀变不是伤害事件，而是独立的队伍异常评分（`settlementType:"luminescence"`、`objectiveKind:"luminescenceTeamScore"`）。
官方口径（蕾米埃尔机制）：

```
耀变伤害 = 【被记录角色的属性 ×（1 + 异化系数）】
           × 耀变倍率
           ×（1 + 异常增伤）
           × 防御区 × 抗性区 × 异常减/易伤区 × 失衡易伤区 × 等级区
```

- 被记录角色的属性：攻击力、精通、穿透率/值、常规增伤，以及对应属性类型
- 异化系数 = 局内蕾米记录时的精通 × 0.02% + 10%（三异常）+ 20%（2影）
- 耀变倍率 = 对应招式耀变倍率 + 局内蕾米精通 × 0.2%（F 级核心技）
- 异常增伤、无视抗性、无视防御均看蕾米埃尔能提供多少
- 异化系数不直接参与耀变伤害构成，而是通过虚曜豆记录的异常效果强度间接参与
- 流明直伤事件不得进入该评分；专用异化公式不读取队友异化乘区
- 异化系数没有上限，理论上可以一直叠

# UI 人工验收清单

机器能判的都由闸门判（`tools/check_ui_contrast.py` / `tools/check_ui_scale.py`）。
本清单只管**闸门判不了**的部分：布局、溢出、状态、观感。

> 核心思路：把评审从「审美判断」降级为「闸门检查」。不同评审员判断不一致，
> 根因通常不是人不同，而是**问题本身没有唯一答案**——所以先把能自动判的拿走，
> 剩下的每一条都必须能填「通过 / 不通过 / 不适用」。

## 怎么用

1. 跑完 A 档（机器）。**A 档不通过直接返工，不进入人工评审。**
2. 拍图：`node frontend/tools/screenshot.mjs --out <目录>`（30 张，含全部节点与视口）。
3. 两人**独立**填 B 档与 C 档。
4. **B 档任一条两票不一致 → 该条自动判「不通过」**（宁严勿松，不为分歧耗时间）。
5. C 档两票不一致 → 第三人裁定；裁不出来也按「不通过」处理。
6. 结论写进 [ui-review-log.md](ui-review-log.md)。**先例优先**：下一轮遇到同类
   场景直接照抄上一轮的结论。

## 1. 三档分层

| 档 | 判定方式 | 谁判 | 约占问题数 |
| --- | --- | --- | --- |
| **A** 机器 | 退出码即结论 | 工具 | ~60% |
| **B** 二值 | 只有「是 / 否 / 不适用」 | 人（双人独立） | ~30% |
| **C** 锚点二选一 | 必须在两张锚点图里选一张 | 人 + 第三人裁定 | ~10% |

## 2. 固定前置条件（不固定，截图就不可比）

| 项 | 取值 |
| --- | --- |
| 浏览器 | Chrome 固定主版本（**记录版本号**）——截图工具用的就是它 |
| 视口 | **1280 / 960 / 560 / 375** 四档，由截图工具用 CDP 精确设置 |
| 缩放 | 100%，`devicePixelRatio = 1` |
| 主题 | 浅色（项目无暗色模式） |
| 字体 | 记录本机实际命中的中文字体（缺 `PingFang SC` / `Microsoft YaHei` 时字体度量不同，须在表里写明） |
| 数据 | 固定 3 位代理人：通用「叶瞬光 `ye-shunguang`」/ 命破「仪玄 `yixuan`」/ 锋御「克拉蕾 `claret`」 |
| 状态来源 | **由 URL 决定**：`?mode=` 决定模式，`?agent=` 决定载入谁 |
| 截图范围 | 整页（full page）；要看视口内的浮层用 `--viewport-only` |
| 文件命名 | `ui-<route>-<state>-<width>.png`，例 `ui-calculator-rupture-375.png` |

> ⚠️ **不要用 `chrome --headless --screenshot --window-size=375,800`**：
> Chrome 在 Windows 上把宽度钳到最小 500px，图会按请求宽度裁切而页面按 500px
> 渲染——**图在骗人**。用 `frontend/tools/screenshot.mjs`（CDP）。

## 4. A 档 · 机器判定（人不需要看）

| B6 | `/calculator` 960 | 单列布局下结果区是否遮住左上角返回按钮？ | **否** | 目视 |
| B7 | `/calculator` 全部宽度 | 长名代理人（「阿斯特拉·雅瑶」）是否溢出卡片？ | **否** | 目视 |

## 6. C 档 · 强制二选一（人看，必须引用锚点）

| ID | 问题 | 锚点 | 规则 |
| --- | --- | --- | --- |
| C1 | 一屏内 6 个模块 + 结果区，是否显得杂乱？ | 锚点 A（色相分层后）/ 锚点 B（分层前） | 选更接近的一张；两票不一致 → 第三人裁定并写入先例表 |
| C2 | 结果区是否「一眼看出是当前面板」？ | 锚点 A / B | 同上 |
| C3 | 说明文字加深后是否「变脏」？ | 锚点 A（4.5:1）/ 锚点 B（2.5:1 修缮前） | 若选 B，**必须给出新的具体替代色值**，不能只写「好看」 |

> **C 档的硬约束**：若两票分歧且第三人也无法裁定，则该条按「不通过」处理。

## 8. 与先例表的关系

[ui-review-log.md](ui-review-log.md) 同时承担两个角色：每轮的**验收记录**，
与 C 档裁定的**先例表**（「某某场景下锚点 A 优于 B」）。下一轮遇到同类场景
**直接照抄**，不再重新讨论。

这是「不同人判断一致」的真正落点：**一致性不是靠让人更客观，而是靠让前人的
结论成为默认答案。**

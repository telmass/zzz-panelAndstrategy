代理人面板计算器

绝区零代理人面板计算工具 · Vue 3 前端 + Python 后端

启动开发环境

本页是开发者指引，不是应用入口。在仓库根运行：

pwsh tools/dev.ps1

启动后访问 http://localhost:5173/ 即为主页（启动页）。 后端 http://127.0.0.1:8000，接口文档在 /docs。 dev server 固定 5173 端口，/api 自动代理到后端，因此不涉及 CORS。

开发入口对照

用途 路径 说明
源码入口 frontend/index.html Vite root 根。不要直接打开：它引用 /src/main.ts，必须经 dev server 或构建才能运行。
开发服务 frontend/ 内 npm run dev 输出到 http://localhost:5173/，即上面的按钮。
构建产物 frontend/dist/index.html 部署时的真实入口，由静态服务器或 FastAPI 挂在 /。前端用 history 路由，服务器需配 try_files 回落，否则直连 /calculator、/guide、/strategy、/strategy/<slug> 会 404。

为什么根目录不是应用本体

别在根目录跑 npx vite：根目录没有本地依赖，npx 会当场下载并运行最新版的 Vite（实测拉到 8.3.4，而项目用的是 6.4.3），它自带的 esbuild 也就跟着走样。 开发服务一律用 pwsh tools/dev.ps1（它以 frontend/ 为工作目录启动），或先 cd frontend。

前端是 Vite 工程，index.html、public/、dist/ 与测试目录都以 frontend/ 为 root 解析。把入口放到仓库根会让 /src/main.ts 解析到不存在的路径、静态资源拷到根目录的 public/、产物输出到根目录 dist/，Vitest 也找不到用例。 目录职责见 docs/directory-layout.md。
